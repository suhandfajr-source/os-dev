- (decision) Sumber input: hasil forge docs/forge/dokumentasi-tools/forged-idea.md (status HARDENED), 6 keputusan terkunci
- (decision) CAP-1 Simpan terkonfirmasi: saat jawaban menyentuh tools/library/layanan/konsep, mesin menawarkan simpan via quick reply chips (Simpan/Edit/Skip); entri tercipta hanya dari aksi user. Alasan: cegah KB penuh sampah.
- (decision) CAP-2 Entri 4 field: nama, fungsi (bahasa awam), kapan dipakai (situasi konkret), cara mulai (install/langkah pertama). Ditolak: tags, link resmi, tanggal+sumber — berat digenerate dan direview.
- (decision) CAP-3 Recall hemat: FTS lokal (FTS5/libSQL) dijalankan sebelum panggilan AI; bila kecocokan ketat, entri disuntik ke prompt builder dengan instruksi 'sebutkan bila relevan, jangan dipaksakan'; tanpa kecocokan = nol panggilan AI tambahan.
- (decision) CAP-4 Kelola via chat: list entri, lihat entri, hapus dengan konfirmasi ulang wajib. List dirender satu bubble gaya WhatsApp; tanpa elemen UI baru di luar chat.
- (decision) CAP-5 Satu KB bertipe extensible: kolom tipe (tool/library/layanan/konsep); menanyakan entri yang sudah ada memperbarui entri lama bukan duplikat; skema siap tambah tipe baru (commit/bug/keputusan) tanpa migrasi.
- (constraint) UI tetap WhatsApp native: semua interaksi (chips, list, konfirmasi) hidup di dalam ruang chat; dilarang menambah tab/halaman/layar baru.
- (constraint) Efisiensi kuota: recall tidak boleh menambah panggilan LLM; pencarian hanya lokal FTS5 di atas KB libSQL yang ada.
- (constraint) Berjalan di stack eksisting: Next.js 15 + React 19, libSQL (@libsql/client), AI Gemini via provider layer yang sudah ada; branch kerja Explore.
- (note) Non-goals: auto-save, tab/halaman UI baru, vector/RAG embedding, fitur Project Partner (PRD generator, dokumentasi git, bug log, dual-account UI), multi-user/sharing.
- (assumption) Aplikasi single-user lokal; tidak ada skenario multi-user pada fitur ini.
- (question) Mekanisme 'Edit' pada chips: edit via pesan chat berikutnya (mesin masuk mode revisi) atau form inline? Belum diputuskan.
- (question) Ambang ketat kecocokan FTS (skor/keyword/parafrase) perlu ditetapkan saat implementasi story recall.
